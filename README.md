# 30 Days of JavaScript Challenge

A comprehensive 30-day JavaScript challenge inspired by [Chai aur Code](https://www.youtube.com/@chaborcode) (Hitesh Choudhary). Each day covers a core JavaScript concept with hands-on coding exercises, feature requests, and LeetCode problems.

## Topics Covered

| Day | Topic | Day | Topic |
|-----|-------|-----|-------|
| 1 | Variables & Data Types | 16 | Recursion |
| 2 | Operators | 17 | Data Structures |
| 3 | Control Structures | 18 | Algorithms |
| 4 | Loops | 19 | Regular Expressions |
| 5 | Functions | 20 | LocalStorage & SessionStorage |
| 6 | Arrays | 21 | LeetCode Easy |
| 7 | Objects | 22 | LeetCode Medium |
| 8-9 | Advanced Topics | 23 | LeetCode Hard |
| 10 | Event Handling | 11 | Promises & Async |
| 12 | Error Handling | 13 | Modules (CJS & ES6) |
| 14 | Classes | 15 | Closures |

## Structure

Each day's folder contains:
- **Main exercise file** — Core concept implementation
- **Feature request file** — Applied mini-project
- **Output screenshots** — Visual proof of results

## How to Run

```bash
# Node.js exercises
node Day1/Day1_VariablesandDatatypes.js

# Browser-based exercises (Day 10, 11, 20)
# Open the .html file in your browser
```

## Tech Stack

- JavaScript (ES6+)
- HTML (for DOM-based exercises)
- Node.js
